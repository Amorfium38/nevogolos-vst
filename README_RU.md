# НЕВЪГОЛОС — VST3

Исходный JUCE-проект вокального аудиоплагина с сатурацией и простым каскадом контроля пиков.

## В проекте
- Форматы VST3 и Standalone.
- JUCE 8.0.8 загружается автоматически через CMake.
- Базовая сатурация на основе `tanh()`.
- Стерео и моно.
- Тёмный интерфейс с золотыми акцентами.
- GitHub Actions для сборки Windows x64.

## Сборка локально
Нужны Visual Studio 2022 с workload **Desktop development with C++**, Git и CMake:

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

## Важно
Это исходный проект, а не готовый бинарный плагин. Текущие настройки обработки фиксированы; GUI пока информационный. Алгоритм контроля пиков — простой и не является сертифицированным brickwall-лимитером. Перед использованием в проектах проверяйте звук, уровни и задержку.
